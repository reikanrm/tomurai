## 1. 円相は元画像の筆跡を使う

原画像は[enso-original.png](../../apps/mobile/assets/enso-original.png)。共有された1024×1024 PNGを変更せず同梱し、元のアルファを[EnsoProgress](../../apps/mobile/src/components/EnsoProgress.tsx)のSVGマスクに使う。独自のベジェ曲線による円相、二値化・描き直しで代替しない。

- 元画像上の表示窓はx=280、y=150、幅480、高さ480。画像自体を切り抜いて保存するのでなく、200×200のSVG内で`scale=200/480`、画像位置`(-280×scale, -150×scale)`として実行時に表示する。
- 写真下部のENSO文字は表示窓の外。元画像の筆先・かすれ・アルファを保持したまま、マスク内にアプリの紙色に合う淡色／黒を描画する。2026-09-26の會田 純一朗の追加依頼（TOM-30）により、円相の前景色だけを深緑からロゴに合わせた黒`#000000`へ変更。ボタン等の緑は維持する。
- 開始前のオンボーディングは`appearance="brand"`で全円相を表示する。役割は画像であり、0問の状態を100%完了とは読ませない。
- 回答中・ホームは`appearance="progress"`。実際の確認数／完了数と分母を表示する。0%では淡い円相、途中は確認／完了した割合だけ黒、100%では黒の円相全体。開始前のロゴも黒。
- 扇形の開始角は下端90度。旧132度開始による太い書き始めの取り残しをなくす。質問を戻る／タスクを未完了へ戻す場合は実際の値に合わせて減らす。
- 値変更は400ms。モーション低減は即時更新。色と筆跡だけに依存せず、数値と読み上げ値も持つ。

原画像を使うことと、全端末でのピクセル一致は別である。縮小率・画素密度・アンチエイリアス・OSのSVG実装は表示差を生み得る。

## 2. 書体と色

Noto Sans JP 300/400/500/700の実ファイルを同梱し、`expo-font`で読み込む。読み込み前に別書体で完成画面を出さず、失敗状態を区別する。`fonts.light/regular/medium/bold`は各ウェイトのファイルへ対応し、軽い書体へ合成太字を重ねる方式にしない。

出典コミット、SIL Open Font License、ファイルサイズとハッシュは[フォント台帳](../../apps/mobile/assets/fonts/README.md)を参照する。全日本語TTF4つを含む約20.9MiBのサイズ増は明示した実装上のトレードオフであり、後日軽量化する場合も文字欠落・ネイティブ互換・ライセンスを確認する。

## 4. 下部アイコンと担当者

下部ナビはモックと同じUnicode文字「○ / ☰ / ⚖ / 🕊」を使用する。[navigation.ts](../../apps/mobile/src/data/navigation.ts)に集約し、専門家の矢印やケアの空円への代替を避ける。絵文字の色・形はOSのフォントに依存するので、全OSで同一画像とは説明しない。

タスク行・担当変更で、担当者のイニシャルアバターと名前を表示する。サンプルは自分／家族A／家族Bであり、実在人物の画像やプロフィールを追加しない。未割当の行には人物アイコンを出さず、選択欄では「—」と未割当ラベルで区別する。担当変更を保存したときに表示を更新し、変更せず閉じたときは旧担当を保持する。現在のサンプル3名は家族人数上限を意味しない。

| 要素 | モックからの対応値 |
|---|---|
| 小アバター | 24×24の円、濃い紙色、罫線1、文字9.5・補助色、上margin2、縮小なし |
| 担当選択pill | 横並びgap6、縦padding6／左6／右12、罫線1、角20、文字12 |
| pill内dot | 19×19の円、罫線1、文字9 |
| pill選択中 | 緑の罫線、濃い紙色、緑の文字 |
| 下部ナビ | 縦padding9／横6、ボタンpadding4・gap4 |
| ナビ記号／ラベル | 記号17・行高25、非選択opacity0.5／選択1、ラベル10/400・行高14 |

担当選択は高さ44px以上の外側Pressable内に元寸法のpillを置き、見た目の寸法とタップ可能な領域を分離する。hitSlopによる隣接領域の重なりは使わない。

## 5. 見た目を合わせても変えないこと

- **ケア文言**：モックの「悲しむことは、愛していた証です。」は採用しない。承認済みの「今の気持ちに、正解はありません。何かを感じても、何も感じなくても。今は、そのままで大丈夫です。」を維持する。引用カードの行数・総高はこの文言と幅に従う。診断・治療・回復度判定はしない。
- **専門家の動作**：會田の明示回答「見た目を合わせ、Mapsの動作を維持」に従う。相談分野カードからGoogle Mapsを開き、モック内の架空人物一覧・相談リクエスト送信・自動予約は移植しない。現在地の取得や家族情報の送信を加えない。
- **掲載表現**：相談分野カードを提携事業者リストと誤認させない。提携地図は準備中で、掲載先・資格・許可の架空記載はしない。広告表示の公開前確認はTOM-1/G04に残す。
- **ケアの3行**：🕊はGoogle Mapsで支援先を探す、🌿は任意の休憩画面、✎は未実装の「準備中」で無効表示する。ノートの項目や保存機能を勝手に追加しない。
- **データ・公開条件**：メモリ内デモのまま。認証・権限・家族同期・本番保存・英語監修・実機アクセシビリティは本作業で完了した扱いにしない。G01〜G06は別途満たす必要がある。
