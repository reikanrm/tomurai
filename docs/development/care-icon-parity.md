# TOM-59 — セルフケアSVG対応表

日付：2026-09-26。決定責任者：テックリード・會田 純一朗。

## 目的と境界

TOM-50配下のTOM-59。C07 / R17 / R19。[委任実装契約](../ssot/po-review-implementation.md)・ADR-0010に基づき、既存Webのセルフケア用SVGだけを移植する。frontend-designの既存意匠優先方針を適用し、新しいアイコン書体・色・アニメーションは導入しない。

参照は `index.html:1212–1235` の `MOOD_ICONS`、移植先は `apps/mobile/src/components/CareActionIcon.tsx`。HTMLの4公開ファイル、気分選択の絵文字、下部ナビ、本文・見出し・ボタン文言、気分を保存しない仕様、任意の開閉と相談/休憩コールバックは変更しない。旧Webの感情断定や気分別自動推薦は取り込まない。

## 対応表

すべて40×40、`viewBox="0 0 40 40"`、`fill="none"`、線色 `#8B6F4E`。パスの文字列・順序・円の中心/半径・線端/結合・不透明度を元SVGと一致させる。

| Web ID / 原稿行 | 移植した形 | 線幅と不透明度 | 現行画面での対応 |
|---|---|---|---|
| tea / 1213 | path × 4 | 1.5、1.3、1.1、1.1。湯気2本のみ0.55 | 水分をひと口 / A sip of water |
| breath / 1219 | circle × 3 | 1.4、1.2、1。中間0.55、外周0.3 | 楽な姿勢で休む、および少し、間（ま）を置く |
| message / 1224 | path × 1 | 1.4、既定の不透明度 | 話せる相手を思い浮かべる、およびグリーフカウンセラーに話す |
| move / 1227 | circle + path | 1.4、既定の不透明度 | 図形を用意・検証。対応する既存行動がないため新しい行動は追加しない |
| write / 1231 | path × 1 | 1.4、既定の不透明度 | 図形を用意・検証。記録機能や未承認の記録導線は復活させない |

SVGは装飾とし `accessible={false}` / `aria-hidden` / `focusable={false}` を付ける。意味と読み上げ名は既存の隣接テキストで伝える。SVGと囲みを40固定・縮小なしにし、文字は折り返せるままにする。従来の36pxの絵文字囲みのみ40pxへ拡大。アイコン単体をタップ対象にせず、既存の行ボタンと選択/展開状態を維持する。
