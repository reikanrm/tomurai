# TOM-37 カレンダー改善の検証

2026-09-26。決定責任者：テックリード・會田 純一朗。

## 変更

- 仕様書/設計書、SSOT `date-picker.md`、ADR-0005をコードより先に更新。
- `CalendarDateField` を死亡日・四十九日法要予定日に共用。月送り、年月指定、直接入力、現在月へ戻る、閉じる、未定に戻す。
- 既存の紙色・深緑・Noto Sans JPを使い、今日の輪郭と選択日の塗り/チェックを分離。ロゴ/料金/権限/通知/法的期限に変更なし。依存追加なし。
- Webボタンはaria-pressed、ネイティブはselected状態、完全な日付ラベル。閉じた後は入力欄へ、月を選んだ後は年月見出しへフォーカスを戻す。
