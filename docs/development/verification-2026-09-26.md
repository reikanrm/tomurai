## POモック視覚修正（TOM-27 / TOM-28）

決定責任者：テックリード・會田 純一朗。専門家は明示回答「見た目を合わせ、Mapsの動作を維持」に従う。[視覚対応表](./po-visual-parity.md)に出典と数値を記録。

### 変更

- 独自の円相パスを廃止し、提供PNGを無加工で同梱してアルファマスク化。元画像とのSHA-256一致を検査。90度開始にし、2/6で太い書き始めが淡色で残る問題を修正。
- 開始前はロゴ全体、開始後は0/10からの実進捗。装飾SVGを読み上げから除外し、親の画像／progressbarと数値で伝える。
- Noto Sans JP 300/400/500/700を同梱。モックの文字寸法・罫線・余白・記号をRNへ移植し、実ファイルでウェイトを分ける。
- 担当者の24pxアバター、19pxの担当選択アイコンを追加。自分/A/Bは合成データ。家族人数制限ではない。
- ケアと専門家を独立コンポーネント化。非断定の承認文言、Google Maps検索、未実装ノートの無効状態を維持。架空専門家や相談リクエスト送信は追加しない。

- `npm test`：23/23成功。担当者4、ケア2、Maps2、ナビ1、進捗/原画像/日付6、資料8。
- `npm run check`、`npm run typecheck`、`npm run build:web`、`git diff --check`：成功。既存4 HTMLに差分なし。
- 独立レビューで円相のマスク、crop、90度開始、brandとprogressの属性分離を確認。進捗専用6件成功。
