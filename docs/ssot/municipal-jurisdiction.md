# 手続きごとの自治体・区選択 — TOM-75

2026-09-27。決定責任者：テックリード・會田 純一朗。TOM-56/C02/C14/R15/R16/R19。PO再監査後の「進めてください」に対する、インフラに依存しないUI・状態の補完。ADR-0010追補。

## 操作と保持

- 該当するタスク詳細で管轄自治体を選ぶ。現在の公式入口は渋谷区/横浜市のみで、関東全域対応済みとは表示しない。「未確認・その他」も残す。
- 横浜市は区を選び、自治体と区それぞれについて「この手続きの管轄を確認した」と操作する。18区名は[横浜市公式の区役所一覧](https://www.city.yokohama.lg.jp/city-info/yokohamashi/ku-shokai/)で2026-09-27に照合。区名の照合は必要書類や管轄の監修を意味しない。
- 自治体/区の変更時は管轄確認を解除。台帳外・他市の区IDや不正な真偽値は確認済みにしない。横浜市で区不明なら個別本文を出さず公式総合案内へ。
- 選択は詳細内で下書きし「この手続きに適用」で反映。適用せず閉じた変更は破棄。同じ起動中に同じタスクを開き直すと適用済み選択を復元する。別タスクへコピーしない。
- 回答を再確定した時と開発のペルソナ/プラン変更時は全選択を解除して再確認する。住所/GPS/故人名から管轄を推論しない。担当変更では管轄を変更しない。
- 現在のAppは一つのローカルケースを扱うメモリ状態のみ。「起動中のみ保持、再起動で解除」を表示し、サーバー保存・家族同期と呼ばない。将来の実接続は本人・ケース・タスクごとのキーと認可を必要とする。

## 表示・データ境界

個別本文は自治体/区/タスク/言語/版/期間/承認が一致する既定の判定を使う。現在の承認済み個別台帳は空のままであり、取得した原文に架空の監修者を付けない。横浜市の区名選択を追加しても、未監修本文を表示できるようにはしない。公式総合ページと区一覧のリンクは個別の必要書類を保証しない。

見た目は既存paper/ink/greenとNoto Sans JPを維持。都市→区→確認→適用の順にし、18区は横折返しのボタンにする。色だけでなく選択記号・radio/checkboxの状態を示し、44px以上の操作領域と長い英語の折返しを確保する。初回は未選択で選択を強制しない。

## 受入・残り

再表示/未適用破棄/別タスク分離/回答訂正時解除、区変更で確認解除、不正ID/型/不足した確認で個別本文拒否、日英表示・公式リンク失敗を試験する。関東全自治体×手続きの台帳・監修・本番永続保存はTOM-56/G03/G04/G06で継続。実通知・生前死後・実請求は今回の範囲外。
