# POレビュー実装：独立レビューの否定条件補足

2026-09-26。決定責任者：テックリード・會田 純一朗。ADR-0010 / TOM-55・56・60。
独立レビューで再現した不整合を、コードの修正より先に契約へ反映する。新たな公開・送信承認ではない。

- **TOM-55**：読み上げの初期問い合わせより後に設定イベントを受け取った場合、イベントを優先する。初期値が遅れて返っても上書きしない。不明/取得失敗/有効時は自動消去しない。通常の再描画やcallback参照の変化で6秒を延長せず、タイマー/購読を破棄し、最新callbackだけを呼ぶ。
- **TOM-60一覧**：データ状態を `unavailable`（未接続）、`loaded`（取得済み）、`error`（取得失敗）で分ける。省略時も未接続。未接続/失敗に件数0や「お知らせなし」を表示せず、古い一覧/既読操作を出さない。ベルも未確認件数を0と読まない。空状態は取得済みの場合だけ。実一覧APIがないAppは未接続を渡す。
- **TOM-60配信候補**：`linkedAt` は現在の有効なLINE連携開始日時として必須。設定有効化/LINE連携/タスク登録のいずれかが当日設定時刻より後なら、その日のイベントを後から補送しない。欠損・不正日時も送信候補なし。時刻はタイムゾーン付きのISO形式で扱い、端末のローカル時刻解釈を使わない。
- **TOM-56欠損**：自治体カタログは行単位で必須文字列/日付/言語/URLを検証し、欠損・不正な行は例外を投げず除外する。有効版が複数なら本文を出さない。
- **TOM-56横浜市**：市IDだけでは区の管轄が確定しない。区が必要なディレクトリは、区ID・区の管轄確認・承認済みレコードの同じ区IDを必要とする。既存UIは区を取得/確認しないため横浜市の詳細を提供せず、一般入口のみを維持する。ここで実在する区IDや監修済み本文を新設しない。

検証は合成入力と決定的なnative port代替のハーネスで実施する。VoiceOver/TalkBack実機、実通知、保存/認証・区別案内の監修は引き続き未完了。
