# 仕様サイトのiPhone風プレビュー — TOM-25

2026-09-27。決定責任者：テックリード・會田 純一朗。R19/R41/R46/R48、ADR-0001追補。

## 依頼と採用範囲

「docsのUIをiphoneのモックにする」という明示依頼を採用。説明サイトの画面別ページで、実フロントをiPhone風の端末枠に収める。UIを別実装した静的画像にはしない。資料本文・要件検索・正本参照を残し、アプリそのものの画面や認可は変更しない。

- 黒い筐体、丸い画面角、島型のカメラ部分、固定の装飾ステータスバー、ホームインジケーターを持つ。装飾は読み上げ・クリック対象外。実端末の時刻/通信/電池状態を表さない。
- 中身はプロダクトdevの同一React Native Web export。標準の内側幅390pxを上限とし、狭い親画面では幅を縮めてレイアウトを再計算する。文字を画像のように縮小しない。
- 上下の装飾とアプリiframeは別領域にし、見出し・下部ナビ・モーダルを覆わない。画面操作はiframe内で行う。
- 選んだ画面、アプリ参照版、再読み込み（この端末内の一時操作が初期化される）、枠なし表示への導線を用意する。画面移動時もカタログのrouteを正しく渡す。
- 狭いdocs画面ではプレビューを説明本文より先に置く。横スクロールをページ全体へ発生させない。表は必要時に表内スクロール。
- 同期時のHTML hashをプレビューURLへ付け、参照版を可視化する。生成snapshot/ADR/previewを手編集せず、同期スクリプトで更新する。

これは見た目と操作確認用のWeb表示であり、特定のiPhone機種のピクセル完全一致、iOSネイティブ挙動、実保存・共有、物理端末試験の完了は意味しない。当初のTOM-25はローカルのみ。既存Vercelへの資料配信は下記TOM-69の追加承認範囲とし、G06解除とは分ける。

## 既存Vercel配信の修復（2026-09-27、TOM-69）

利用者は、欠落したビルド処理の追加・検証・commit/push・再デプロイ・URL確認を明示承認した。対象は既存 `tomurai-docs.vercel.app` の説明資料と合成データによる操作プレビューのみ。プロダクトmain、Vercelのアクセス保護・契約プラン、GCP、実認証/保存/通知/課金を変更しない。正式アプリ公開のG01–G06は引き続き未達。

- docsの `tools/vercel-build.mjs` と `vercel.json` を追跡し、ビルドコマンドと出力先を一致させる。
- snapshotに記録された公開productリポジトリの40桁コミットを取得。動くdev先端を毎回取得しない。dirty版・別repository/branch・不正SHAは拒否する。
- lockfileで依存を導入し、`/preview` 配下のRN Webを再生成。検証用の招待練習とTOM-72の開発メニューを明示フラグで有効化。他の外部接続設定は持ち込まない。
- 同期スクリプトを共用し、固定版の要件/catalog/ADRを照合する。Windows/Linuxの改行差は正本テキストhash計算前にLFへ正規化。ビルドHTMLのhashは実生成物から取得し、別環境の旧hashを偽装しない。
- 配信物は `index.html`、資料の `assets/`、`data/`、実アプリの `preview/` だけ。ソース、Git、設定、秘密、node_modulesをルートごと配信しない。symlink、想定外拡張子、欠落を拒否する。
- 古いローカルpreviewやビルドキャッシュがなくても作れることを検証。取得・照合・ビルド失敗時は停止し、古い成果物を成功扱いにしない。
- デプロイ成功とブラウザーの表示確認を別に記録。401/ログイン保護は解除せず、確認できない範囲を明記する。
- 配信調査で、稼働版はdocsの `claude/nice-clarke-2seb5z` / `3bd39b2` にある認証・テーマ・用語説明・ローディングを含むと判明。main未統合の既存機能を失わないよう統合し、iPhone枠と固定版ビルドを両立させる。既存DOCS_PASSWORDとセッションCookie方式・有効期間は維持し、秘密値の取得・変更は行わない。未認証で資料/preview/データ/JS/ADRへ直アクセスしても拒否する。認証用middlewareは配信基盤で実行し静的distへはコピーしない。

### TOM-72：法人ペルソナの公開資料への反映

2026-09-27の「Vercelへの反映完了」指示により、保護された資料サイトのビルドだけ `EXPO_PUBLIC_DEVELOPMENT_MENU=true` を明示する。TOM-71の法人社員本人/招待家族/代理担当、シーン選択を同じ製品UIで確認するためであり、通常製品ビルドや実認証の権限は変えない。従来の合成招待フラグも維持する。他のEXPO_PUBLIC設定・dotenv・秘密値は継承せず、実APIに接続しない。パスワード保護、固定コミット検査、一般公開の未達Gは維持する。

デプロイ成功だけでなく、公開URLの再読込後の参照コミット、法人切替、ノート入力/本人確認の合成操作を確認する。入力はメモリ内のみで再読込により消える。

全画面のroute/タイトル/同一build参照、再読み込み、狭い幅320/390px・デスクトップ、iframe内のケア選択/家族の操作確認を試す。資料の要件検索とナビも維持する。検証結果はTOM-25の証跡へ。
