## 送信・記録

TOM-58の確認画面と同じ宛先/項目/版/操作IDを固定した最小スナップショットのみ受ける。ノート・全回答・香典・AI本文の自動添付や家族DBの検索APIは作らない。外部問い合わせ先への遷移は自社受付済みの案件にしない。掲載契約・支払いは閲覧の根拠にならない。

送信処理の受領情報は operationId/相談ID/宛先ID/受領日時/状態のみ。通信断はuncertainで、同じ操作ID・同じpayload以外を再送しない。本文の保存期限/削除主体が未承認なら実受付を開始しない。送信後の第三者保管は元ノートの共有撤回と異なり、受領先への削除依頼・結果確認のフローが必要。

監査に許可する情報：仮名actor/tenant/case ID、操作種類、時刻、成否、版、理由コード。本文・氏名・連絡先・トークン・全文エラーは入れない。保存期限未設定を無期限と解釈しない。復元時に期限切れ/削除/撤回を再適用する。
