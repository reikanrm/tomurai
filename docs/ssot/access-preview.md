# 権限・プラン確認と無料タスク表示

2026-09-26。決定責任者：テックリード・會田 純一朗。TOM-38 / TOM-39。C03/C04/C05/C18、R01/R05/R06/R19。実装前に確定した範囲。

## 開発確認

Androidの既存専用AVD/Expo Goを使用する。`__DEV__` の時だけ画面上部左の設定入口から開発メニューを開ける。開発バナーは復活させない。メニュー内で画面、承認済み/参加承認待ち、支払権限、回答担当、プラン（無料/β/単独/家族/法人/失効）、承認済み人数（1名/複数名）を選べる。人数はテスト条件であり商品上限ではない。

支払権限と回答担当は独立。法人プランは家族側の利用権を表し、法人担当者の閲覧権ではない。変更はメモリ内のみ。URL、保存領域、請求API、実認可を変更しない。公開ビルドでは入口/操作を無効とする。切替時に詳細・入力・購入シートを閉じる。初期は承認済み1名/回答担当兼支払者/無料。

## 無料2件

最初の質問確定時に、予定日→なければ目安日→不明は末尾、同日はID順で2IDを固定する。開発メニューで質問を省略した場合は、その時点の合成データから一度だけ固定する。空配列も確定値で、未確定(null)と分ける。完了、フィルタ、再抽出、プラン切替で補充しない。消えたIDが復活すれば元の閲覧権に戻る。

在籍→利用権→一覧フィルタの順。未承認は家族タスクを0件、単独プランは承認済み1名の時だけ全件。家族/法人/βは承認済み家族に全件。失効は無料固定2件。詳細表示と更新でも同じ判定を行う。回答の閲覧・変更は回答担当だけ。無料の進捗表示は閲覧可能なタスクだけを分母とする。

非公開タスクをぼかして描画しない。TOM-41（2026-09-26追加、會田 純一朗）で棒状の背景をやめ、通常のタスク一覧と同じ文字・チェック枠・担当欄・行の区切りを持つ背景に変更する。背景は公開の一般タスク名と固定の「日付は個別に確認」「担当：未割当」だけで構成し、実際の非公開タイトル/日付/担当/件数/完了状態を渡さない。未割当の通常行と同じくアバターは表示しない。

背景と通常行の寸法を共通化（上下16px/本文左33px/19pxチェック枠・線1.5px/タイトル15px・行高22px/全幅の1px罫線）。Noto Sans JPと色も共通。横幅を実測し、SVG文字や罫線の引き伸ばしをしない。日本語/英語を折り返してからぼかす。案内カードの上下に行が見えるようにする。背景は読み上げとタップの対象から除外し、フィルタや完了で背景を変えない。非公開情報を扱うAPIの制限は維持する。

Figma指定ノードの柔らかいぼかしを維持し、Tomuraiの紙色・深緑・Noto Sans JPを使う。相続の一般注意、公的リンク、ケア、一般Maps検索は制限外。未承認には個人の日付・選択を渡さない。

TOM-41レビュー追補（2026-09-26、會田 純一朗）：背景文字が読み取れるとの指摘を受け、Gaussian blurの標準偏差を3から6へ強める。背景の不透明度0.7・行構造は維持し、案内カード/ボタンはぼかさない。公開固定文言のみを描く境界は変更しない。

## 導線と未接続の扱い

| 現在の権限 | 無料でのボタン | 確認画面 |
|---|---|---|
| 承認済み・支払権限あり | プランを確認する | 単独/家族の人数条件、月/年、税込価格、Stripeによる支払いの案内 |
| 承認済み・支払権限なし | 契約者にリクエスト | 契約者への依頼内容と未送信の説明 |
| 参加承認待ち | なし | 承認待ち。課金で参加承認を迂回しない |

ユーザー最終回答は「未作成・導線だけ先に実装」。Stripeリンクは設定せず「決済の準備中」、リクエストAPIも未接続のため「送信の準備中」。実送信/請求/利用権付与はしない。購入画面から戻っても有料化しない。支払権限の移管後は現在の権限で判定し、招待由来かどうかで固定しない。

C18の以前のリンクなし案内から、支払権限者向けStripe導線を希望する方針へ更新する。ただし今回は未接続の案内のみ。G01/G02/G04/G06と対象ストアの条件は未達のまま。日本の外部決済は無条件にStripe直リンクで公開できるとは扱わない。Googleの参加要件・リンク先・Play課金併設・API、Appleの対象OS/entitlement/併設/開示等を公開時に再確認する。
