# 再監査後の実装契約 — 質問・残作業・相続確認・ケア

決定責任者：テックリード・會田 純一朗。2026-09-26。TOM-42/43/45、C01/C03/C07、R13/R15/R17/R18/R19/R46。実装前に記録。香典台帳TOM-44はPOモック待ちで実装しない。

## 1. 完了は作業ごと（TOM-42）

- 法要を実施したという回答は法要本体だけの完了。お布施・会食・開眼供養・返礼品・準備の未完了を消さない。
- `RitualWorkHistory` に初七日/四十九日の準備候補を確定回答から発行したことだけを記録する。未操作タスクに進捗レコードがないことを「未発行」と誤解しない。実施日や完了ではない。
- 初回から初七日実施済みなら準備候補を新規発行しない。いったん未実施/不明として発行した候補は、実施済み変更後も現在の選択に適用するものを保持する。
- 四十九日は初回から実施済みでも、お布施・必要な会食/開眼供養の確認と法要後作業を残す。準備候補は既発行の場合だけ残す。個別に不要とした分岐は非表示にし、進捗と担当の履歴を消さない。
- 任意で完了回答に直接対応しない作業は「対象外にする／対象に戻す」を選べる。`TaskProgress.notNeeded` を完了と区別。全完了判定は各作業が完了または明示対象外、かつ必要な不明回答がないこと。対象外を完了件数へ足さない。
- 初七日のお供えは必要性確認と準備、会食は必要時の手配、後飾り祭壇は時期・方法を確認した上で片付けるまでを説明する。
- 初七日の補足は「葬儀当日に前倒しして行う場合があり、火葬・収骨後や、告別式後・火葬前の式中（繰り込み）初七日など。名称や形式は寺院等に確認」とする。普及率・一律の義務・宗派共通の定義を断定しない。

## 2. 条件付き質問（TOM-43）

1名の回答担当が下書きを入力し、最後の確認で一括適用。既存10問は維持するが上限は撤廃。`unknown` と未入力を区別し、すべての表示対象について選択か「あとで確認」を経て確定する。

| 追加確認 | 表示条件 |
|---|---|
| 葬儀の実施、法要案内の希望 | 全員。宗派だけから希望を決めない |
| 初七日の実施状況、四十九日の実施状況 | 法要案内を希望 |
| 初七日会食 | 初七日が未実施/不明 |
| 四十九日予定日 | 四十九日が未実施/不明。未定可、死亡日以前不可 |
| 本位牌、会食、返礼品、開眼供養、後飾り祭壇 | 四十九日を「行わない」以外 |
| 納骨の予定、香典返しの状態、相続放棄等の検討 | 宗教・法要から独立して全員、いずれも不明可 |
| 追加彫刻 | 納骨を四十九日前後に予定する場合 |

質問IDで遷移を管理する。分岐を変更したとき隠れた回答の下書きを保持し、隠れた問いは確定の必須条件にしない。再表示時は復元。法要確認画面・タスク完了から変更した内容を質問再編集で古い回答に戻さない。質問数は回答に応じて変わる旨を表示。

既存8回答の利用：世帯主、年金、健康保険、不動産、自動車、個人事業、生命保険、相続人について、該当すれば関係機関への手続き確認候補、不明なら対象確認候補、明示noなら該当候補を除外する。健康保険は選択した制度の窓口確認、相続人は複数/単独で確認の説明を分ける。必須手続きの断定や法的期限の算出はしない。安定ID・日英説明・確認先の一般名を用い、詳細の出典/自治体承認はG03に残す。

固定無料2IDは全質問を初めて確定した時に選定し、回答修正・完了・非表示でも再補充しない。未入力状態や途中の候補から確定しない。安全注意・ケアの無料制限外、未承認家族の非開示は維持。

## 3. 四十九日完了確認後の相続案内（TOM-45）

従来D+6〜12/D+48〜54に加え、法要の完了を確認した操作日から7日間、独立した相続確認カードを表示。`EventDates['forty-nine']` は実施日や法的起算日ではない。`completed` と `confirmedOn` の両方を渡し、取消後の旧イベントだけで表示しない。再完了時は新しい確認日。未来/不正な確認日は無効。相続の一般注意は常設し、無料制限・宗派・法要不要から独立。

文言は「四十九日法要の実施を確認しました。相続についても、必要に応じて確認できます」等とし、今日が実際の法要日だったとは言わない。死亡日+90日/残り40日は生成しない。相続人本人の起算・申述・受理・伸長を混同しない。起動中の定期更新に加えフォアグラウンド復帰時にJST日付を再評価する。OS/LINE配信は未接続のまま。

## 4. 今できる小さな選択（TOM-45）

ケアの指定本文・補足・既存気分ボタン・Mapsを維持し、気分にかかわらず選べる任意の小さな行動を追加する。「水分をひと口」「楽な姿勢で休む」「気持ちを言葉にしなくても、話せる相手を思い浮かべる」。選択すると短い案内が開き、閉じられる。達成チェック、回復スコア、日記保存、家族共有、感情推論は追加しない。心身の状態を評価せず、合わなければ選ばない案内を添える。
