## 独立して保存する状態

- membership：invited / pending_approval / active / left（人数上限なし）
- subscription：pending / active / cancel_scheduled / expired。決済の失敗・処理中は独立したpayment record。
- entitlement：free / beta / b2c_solo / b2c_family / corporate。サーバーが開始/終了・証拠から計算する。
- corporate_case：approved_not_started / scheduled / active / ended。承認・予約と実際の開始を分ける。
- consent：誰が何の版にいつ同意したか、撤回/失効を履歴化。
- refund/correction：請求の訂正と利用権の変更を別々に追跡する。

同一グループのB2C/法人の支援期間重複を作らない。βなどの技術検証権利は本番請求根拠にしない。
日時は保存・比較を統一し、表示と月/年の境界はJST・暦月で試験する。

## B2C・家族

| イベント | 条件・処理 | 請求/利用権の結果 |
|---|---|---|
| 購入開始 | 支払者本人、価格版/周期/適用日の明示同意 | pending。画面の成功表示だけで有料にしない |
| 決済確認 | 署名とプロバイダー照合、重複/順不同対策 | 支払済み期間の権利を付与。単独は1名、家族は承認済み全員 |
| 招待作成 | 招待権限と不正対策 | 請求/プラン/枠に変更なし |
| 2人目参加 | 家族権利がなければ差額と適用日への支払者同意→決済/権利確認 | 承認とアップグレード成功後のみactive。失敗なら参加確定しない |
| 3人目以降参加 | 在籍/招待/承認を検査 | 追加料金なし。人数上限なし、AI枠増加なし |
| 家族から1名へ | 本人が単独への変更を選択 | 次回更新で変更。自動追放/自動遡及返金なし |
| 月払い↔年払い | 本人同意 | 次回更新で変更。招待時の即時upgradeと混同しない |
| 解約予約 | 支払者本人 | 更新停止、支払済み期間末まで家族権利 |
| 支払者退会/削除 | 更新停止、新支払者の同意を別途取得 | 既払期間は他メンバーに残す。削除本人の権限は即時失効、カードを流用しない |
| 期間末/更新未成立 | 検証済み期間の終了。未定のB2C猶予を勝手に追加しない | free固定2件。共同データは保持、香典は既存共有範囲で読取のみ |
| 誤請求/二重請求 | 運営確認・訂正監査 | 返金と権利を個別照合。返金Webhookだけで家族記録を削除しない |

検証用価格（税込）：単独980円/月・9,408円/年、家族1,480円/月・14,208円/年。
3人目以降無料。人数上限なしは単独価格を家族全員へ適用する意味ではない。
即時upgradeの按分/端数/見積有効期限はサンドボックスで具体化し、見積と請求の一致を試験する。

## 法人支援・年契約

| イベント | 条件・処理 | 請求/利用権の結果 |
|---|---|---|
| 法人招待/申請承認 | 法人別の適用条件と方式 | approved_not_started。ケース請求なし |
| 本人が利用開始 | 本人明示同意、資格/有効契約/未開始を同時に再検証 | active、実開始から12暦月。同一group1回の一意制約とトランザクションでケース1万円税抜を1回 |
| 開始API再送/同時操作 | 安定operation IDとcase一意性 | 既存caseを返す。請求/終了日を増やさない |
| 個人有料から切替予約 | 利用者と法人が既払期間末の翌日を確認 | scheduled、B2C更新停止。予約では請求しない |
| 切替当日 | 資格再確認、B2C終了、開始条件を原子的に判定 | 適格なら1回開始。不適格なら開始/請求しない。即時返金切替は運営例外 |
| 同一groupに他法人申請 | 支援重複と既利用を検査 | 同時法人・2度目の12か月支援不可。他groupとの同一人推測は自動統合しない |
| 退職/会社不更新 | 新規開始の資格を止める | 既存case12か月は維持。家族に自動請求しない |
| case満了 | 開始＋12暦月、月末/うるう日を検証 | 明示的な個人契約がなければfree。法人へ自動case再請求なし |
| ケース請求書支払遅延 | 月末締め翌月末払い、7日猶予＋確認 | 新規開始停止。開始済みケースは維持、家族へ督促しない |
| 基本料金支払前 | 初回/更新時の前払い未成立 | 新規開始不可。ケース請求の7日猶予とは別 |

法人基本料金額はG01で未確定。仮の0円で本番契約を作らない。
年契約は自動更新、不更新受付は更新1暦月前まで・登録窓口の受領時刻基準。
存在しない月日は月末に合わせ、JSTの具体的な日時を契約表示する（G04確認）。
通常の2か月前更新メールは送らない。価格変更の例外通知は2か月前＋明示同意。
新料金に同意なし・不更新通知なしなら旧料金表で更新する。対象人数区分の申告と同じ料金表内の区分変更は分ける。
請求書発行・入金照合は初期は会社側で手動。家族の私的情報は法人請求明細に出さない。

## βと失効

βは期限付き無料権利で、カード必須・自動有料化をしない。通常無料AI0とβ検証枠を区別する。
有料権利の失効は削除と別。本人ノートの既存閲覧・共有撤回・削除と既存指定相手の閲覧を維持する。
共有権限そのものの撤回/脱退/アカウント削除は、課金期間が残っていても即時反映する。
