# 自治体別の案内 — TOM-56

決定責任者：テックリード・會田 純一朗。ADR-0010。C02/C14/R15/R16。

タスク詳細で自治体を選び、管轄根拠が確認された自治体ID＋タスクID＋言語＋有効版が一致する承認済み本文だけを表示する。自由入力やGPSから制度/書類/期限を生成しない。選択だけで管轄確定した扱いにせず、確認チェックがない場合は公式の一般入口だけを示す。

2026-09-26に読み取った公式一般入口は [渋谷区](https://www.city.shibuya.tokyo.jp/contents/case/okuyami.html) と [横浜市](https://www.city.yokohama.lg.jp/life/gohukou.html)。これらのURL確認は手続き本文の監修・管轄の確定ではない。未監修本文のカタログは空のまま。横浜市は区別案内が必要なため市選択だけでは詳細を出さない。関東全域の目標は変更しないが、2入口の登録を全域完成と呼ばない。

必要なコンテンツ契約：自治体ID/タスクID/版/言語/本文/公式URL/確認日/承認者/有効開始終了日。破棄済み版、重複した有効版、別自治体、未監修英語、許可ホスト外URLは表示しない。任意の法要・私人宛手続きへ自治体窓口を無差別に割り当てない。

ローカルでは詳細パネルを開いている間だけ選択をメモリに保持する。閉じて開き直すと再確認し、家族へ共有しない。APIの認可されたtask projectionから表示する境界を維持する。保存/同期・監修・全関東台帳・月次更新ジョブは別工程で未完了。
