# ADR-0012：共通開発スキルと変更契約検査

- 日付：2026-09-27
- 状態：採用（ローカル実装対象。公開・外部設定の承認ではない）
- 決定責任者：テックリード・會田 純一朗
- 関連：TOM-67、C01/C05/C15、R43/R44/R46/R47、G01–G06

## 背景

CodexとClaude Codeで同じ開発規則を守れるようにしたいという明示依頼。モデルへの長い指示だけでは、仕様逸脱・他人の差分の混入・未実施試験の誤報を十分防げない。現在のAGENTS/TAKTの境界を維持し、プロダクトの権限や未決の生前ノート第4問は変更しない。

## 決定

`.agents/skills/tomurai-development/SKILL.md` を手順の正本にし、Claude Code用スキルはそこへ接続する。`CLAUDE.md` は `@AGENTS.md` を共有する。全案件の個人設定を変更する方式や、業務仕様の二重コピーは採用しない。

票・要件・変更ファイル・文書判断・検査コマンド・実結果への参照をJSON契約にする。構造と実Git差分をNode標準ライブラリのみで検証し、既存CIに追加する。コマンドは契約から実行しない。細則と受入条件は[SSOT](../ssot/development-harness.md)に置く。

## 代替案と影響

- 指示だけ：軽いが機械的な取りこぼし検知がないため不採用。
- エージェント別に規則全文を複製：更新漏れが増えるため不採用。
- shell文字列をフックで一律判定：迂回可能で正常作業も壊すため、本票では採用しない。
- 厳密パス契約：変更のたびに更新が必要だが、巨大なglob許可や既存契約流用を避けられる。

CIと指示は認可基盤ではない。管理者によるbranch protection/必須レビュー、秘密検知、実サービスの権限分離は別途。実行していないClaude Code・Codexの自動選択、監修、実機、公開を完了としない。
