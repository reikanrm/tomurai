# ADR-0002 家族人数は上限なし

- 日付：2026-09-26
- 状態：採用
- 決定者：テックリード・會田 純一朗
- 対応：R01–R03、R20–R22、TOM-22

家族の人数上限は設けない。旧10名案は不採用。
1人980円/月、2人以上1480円/月という検証価格を維持し、3人目以降の人数追加料金はない。
AIは家族共通枠で人数による増加なし。βの回数設定は正式商用上限の決定ではない。
単回招待/レート制限/認証/参加承認は人数上限と別の安全対策として残す。
招待作成だけで家族プランへの増額同意を推定しない。
メンバーを独立レコードで扱い、ページ分割・同時操作・再参加を試験する。
