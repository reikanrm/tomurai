# ADR-0004 — 法要の任意分岐と相続注意を分離する

- 日付：2026-09-26
- 状態：採用（実装・監修・公開の完了ではない）
- 決定責任者：テックリード・會田 純一朗
- チケット：TOM-31〜35、親TOM-6

## 背景

Sep9改善リストを監査したところ、React Nativeには固定タスクしかなく、回答を確定しても抽出に使っていなかった。こころのケアの上部文言のみ反映済みで、法要分岐、日付、9つの言葉、相続の節目確認が欠けていた。

## 決定

1. [詳細SSOT](../ssot/bereavement-guidance.md)と別repo仕様・設計をコードより先に更新する。
2. 初回10問は増やさず、回答後に任意の法要確認画面を設ける。宗派から義務を推定せず、不要・不明を保持する。
3. 死亡日起算の目安日、実際の予定、本人の完了確認を分離する。安定IDと進捗を分離し再抽出で完了/担当を失わない。
4. 相続の安全案内は法要ToDoと別。初七日まで待たず最初から案内し、売却・処分前にも常設する。90日/残り40日など誤った期限を生成しない。
5. 言葉は最大1枚、閉じる/オフ可。過去の節目を一斉に見せない。感情を判定したり回復を評価しない。
6. 全画面の開発用文言を除く。未接続機能の境界は技術文書に残し、未実装の操作を可能と偽らない。既存書体・色・黒い円相・Maps動作は維持する。

## 代替案と理由

初回質問を増やす案はC01に反する。一律で法要を必須化する案は宗派/家庭差を扱えない。死亡日+90日で相続期限を計算する案は法的起算を誤る。文字だけを追記する案は回答連動・取り消し・再抽出の欠落を解消しない。

## 結果・残る制約

画面内動作は独立して検証可能になるが、メモリ内実装は保存・認可・家族同期・配信の代替ではない。TOM-4/5/9、公開ゲートG03/G04/G06等は別途必要。C06香典台帳の項目拡張や通知の外部送信を本決定で追加承認しない。
