# ADR-0013：主要アイコンをIconoirのReact Native部品へ統一

- 日付：2026-09-27
- 状態：採用（利用者の明示した図柄変更。公開承認ではない）
- 決定責任者：テックリード・會田 純一朗
- 関連：TOM-68、C07/C15、R19/R41/R44/R46/R48、G03/G06

## 背景

心のケアの気分5種がOSの絵文字表示に依存し、既存の控えめなアプリの線画と質感が揃わない。利用者からIconoirのReact Nativeコンポーネントを指定し、かわいらしくする依頼があった。

## 決定

公式 `iconoir-react-native@7.12.1` を固定し、共通AppIconと意味別adapterを使う。気分は淡い丸背景＋28pxの図形と控えめな選択チェック、専門家/ナビ/行動も同ライブラリで統一する。[対応表・受入](../ssot/iconography.md)を正本とする。

TOM-27/28/59の「Unicode・Web SVGと完全一致」は指定した図柄だけ置き換える。円相、担当者アバター、文字、機能、権限は維持。既存SVG依存を再利用し、新しいネイティブSDK・画像生成・送信先は追加しない。

## 比較と制限

絵文字は端末差があり、独自トレースは指定ライブラリと保守性の要件を満たさない。公式部品の静的named importは統一しやすいが、依存とバンドルへの影響をビルドで確認する必要がある。気分の図柄から診断・分類を推定しない。動作試験と視覚確認を行い、実機/監修の未完了は残す。
