# ADR-0016 生前ノートの型付き入力と収集境界

- 日付：2026-09-27
- 状態：採用（ローカル製品実装、実接続保留）
- 決定責任者：テックリード・會田 純一朗
- 対応：TOM-73 / C06・C15・R08・R13・R19・R43

## 背景と判断

残り31項目を全実査した。すべてを一般文章欄にするとPOの表/選択の意図を失い、保留している医療/資産/資格情報の収集を迂回してしまう。

[項目契約](../ssot/life-note-fields.md)に沿って17項目を追加し、14項目は理由付きで保留。既存5項目のうち1項目を選択＋補足へ是正する。安定項目IDと欄ID、型・選択肢・長さを一元管理する。項目値は文字列/キー付き値/行配列を区別し、サービスで未知キー・型・選択値を拒否する。projectionは深いコピーで返し、応答後の変更で保管値を書き換えられないようにする。

代理承認は既存の項目単位で、追加欄を既存委任へ自動付与しない。入力型ごとのUIと確認表示を共用する。モックの状態ピルだけで内容を記入済みにせず、未保存・代理下書き・本人確定を分ける。

実接続・監修を省略した31項目完成とはしない。既存自由文の「今、大切にしたいこと」があれば補足として保持し、新しい選択値を推測しない。本番データ移行は未存在/未接続であり、このローカル互換処理を実DB移行の証拠とは扱わない。
