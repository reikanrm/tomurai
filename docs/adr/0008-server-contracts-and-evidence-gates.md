# ADR-0008 — 保存・通知の契約実装と実接続の証拠を分離する

- 日付：2026-09-26
- 決定責任者：テックリード・會田 純一朗
- 状態：設計確認待ち。追加指示によりインフラのgrill完了まで実装保留。DB採用・実支出・監修・公開の承認ではない
- チケット：TOM-46/47、実装単位TOM-48/49、公開条件TOM-13〜18

## 背景

保存・家族同期・実通知・監修・両OS実機検証までの完了を依頼された。現行アプリはメモリ内操作のみで、認証/API/DB/配信基盤は存在しない。実機監査で確認できたAndroidはエミュレーターのみ。会社アカウント、予算、監修担当、実機の証拠を包括的な実装指示で補完しない。

## 決定

### 確定した管理方針（2026-09-26）

テックリード・會田 純一朗は、会社のGoogle Cloud組織配下で管理する方針を承認した。これは管理方針の承認であり、移行実行・IAM変更・費用の承認ではない。移行先組織、必要権限、既存リソース、継承される組織ポリシーへの影響を読み取り確認し、実行範囲の承認後に移行する。インフラ全体のgrillと実装保留は継続する。

### 引き続き確認待ちの実装案

費用再検討：會田の「高すぎます」という回答により開発月4万円案を採用しない。ローカル開発＋必要時だけクラウド検証する削減案を比較するが未採用。低予算化を本番の復旧目標・認可・安全性の緩和承認に読み替えない。希望予算・構成の共有理解まで実装保留。

見積り先行の進め方を承認：開発・検証、30家族β、2,000人の参考ケースを公式料金で試算してから、予算上限を判断する。[2026-09-26概算](../development/infrastructure-cost-estimate-2026-09-26.md)は構成比較案であり、金額・Cloud SQL採用・HA/DR構成・支出を承認した記録ではない。RPO1時間/RTO4時間は未実証の設計目標を維持する。

以下は確認待ちの実装分割案。2026-09-26の追加回答でGCPプロジェクト作成済み、PixelとiPhone保有を確認した。会社アカウント権限・接続・OS/機種詳細は未確認。監修担当は未定で、当面は資料準備までとの指示。設計の共有理解が確認できるまでコード実装・インフラ構築を再開しない。

1. [追加SSOT](../ssot/server-sync-and-notifications.md)と仕様・設計をコードより先に更新する。
2. 保存は、確定回答とタスク更新を分けたサーバーコマンド契約から着手する。DB非依存のトランザクション境界とテスト専用アダプターで認可・競合・再送を検証する。
3. 認可はサーバーの現在のmembership/権利で判定。開発用プラン切替を信頼しない。原状態の全量取得・全量上書きAPIは作らない。
4. 通知は既決LINEまとめ通知の対象判定から実装。実チャネルの接続・署名検証・永続キュー・送信試験は後続であり、純粋関数の合格を実送信の合格としない。
5. 監修はコンテンツ版ごとの担当者・承認証跡、実機は機種/OS/ビルド/操作結果の証跡で判定する。監修者の代わりに承認せず、エミュレーターやWebを実機扱いしない。

## 代替案と影響

AsyncStorage等へ家族情報を平文保存して保存完了とする案はR12のオンライン/失効境界を満たさない。クライアントstate丸ごとのPUTは回答担当と共同作業権限を混同する。GCPの未承認構成を作成する案はG01/02未達のため採らない。契約テストは先行できるが、永続化・2台の実同期・実通知は未完了として残る。アプリ画面は本対応だけでは保存済みに変わらない。
