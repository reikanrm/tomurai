# ADR-0003 POモックを実装へ移し、円相を進捗に使う

- 日付：2026-09-26
- 状態：採用
- 決定者：テックリード・會田 純一朗
- 対応：C07/C08、R17/R19/R41、TOM-23、TOM-24、TOM-27、TOM-28

## 採用するデザイン

[POモバイルモック](https://claude.ai/public/artifacts/8d861714-202e-4eaf-a593-4d9916495aeb) の紙色 #F5F3ED、深緑 #2B5545、墨色 #232922、余白、細い区切り線、4タブ、操作シートをReact Nativeに移す。
文字はモック指定のNoto Sans JP 300/400/500/700を同梱して読み込み、本文/見出し/補助ラベルでサイズ・ウェイトを分ける。フォールバック書体や合成太字だけに依存しない。[フォントの出典・ライセンス](../../apps/mobile/assets/fonts/README.md)を保持する。
画面はヘッダー→円相/見出し→本文/操作→下部ナビ。円相だけを特徴的な表現にし、装飾的な動きを増やさない。

## 差分

- TOM-24初稿の独自SVG筆形状はTOM-27で置き換える。共有された1024×1024 PNGを変更せず同梱し、元画像のアルファをSVGマスクとして使用する。円相部分を画像座標x=280/y=150、480×480の範囲で実行時に表示し、背景やENSO文字を含めない。輪郭・かすれを描き直したり、二値化したりしない。マスクへ色を重ねるため、筆跡の元データとアプリの色を分離する。
- 最初の開始画面は円相全体をブランドとして表示する。質問を始める前に100%完了したようには扱わず、開始後の質問確認数は0/10から表示する。
- オンボーディングとホームで同じ部品を使うが、質問確認数とタスク完了数は別。
- 下部タブの専門家は「⚖」、こころのケアは「🕊」を用いる。担当者はモックと同じイニシャルアバター構成で示す。色だけに依存せず、担当者名も表示する。
- 専門家ページはカードの書体・寸法・罫線をモックに合わせるが、2026-09-26の明示回答「見た目を合わせ、Mapsの動作を維持」に従い相談分野のカードとする。専門家の一覧・相談送信は作らず、Google Mapsへ。架空事務所を載せない。
- 感情を決めつける文言や不正確な法的期限をそのまま採用しない。期限は未接続と表示する。
- 個人情報を永続化する前に認証/認可/暗号化を実装する。現時点はメモリ内の合成データのみ。

## 実装

Expo 57 / React Native 0.86、依存lock。SVG内で原画像のアルファをマスクに使い、数値/読み上げ/モーション低減に対応。進捗の扇形は下端90度から開始し、太い書き始めが欠ける旧132度開始を使わない。
React Native Webの書き出しを仕様サイトでも使用する。独立した見た目だけのHTMLモックは新設しない。
Web成功はAndroid/iOS実機成功の代替にしない。OSの絵文字、文字レンダラー、拡大設定による差までピクセル一致とは表現しない。

CSSからReact Nativeへの値の対応、承認済み文言との違いは[POモックとの視覚対応](../development/po-visual-parity.md)に記録する。試験・見た目の合否は本ADRではなく、実際の検証記録と各Linearチケットに残す。
