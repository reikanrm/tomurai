# ADR-0011 — 法人料金を未設定に保つ純粋ドメイン

日付：2026-09-26。決定責任者：テックリード・會田 純一朗。
状態：委任範囲のローカル実装方針を採用。実契約・請求・公開は未承認。

## 背景

TOM-63の社員数×月N円を、既決の年契約・年額前払い・人数年間固定と両立させる。Nと人数帯はPO待ちで、仮値を商品価格にすると無断請求につながる。

## 決定

[専用SSOT](../ssot/corporate-pricing.md)の全体単価方式と版付きスナップショットを採用する。未設定は見積不能とし、家族人数を算定しない。ケース開始は本人同意・法人対象確認・入金/資格・B2C重複・操作ID・revisionを検査する純粋状態遷移だけを実装する。ケース1万円税抜、家族0円、12暦月・1グループ1回の既決を保持する。実際の税率や単価は補完しない。

## 結果

合成データで異常系を先に検証できるが、サーバー認可・DB一意制約/トランザクション・実入金・実請求を通した証拠にはならない。返却する状態候補はAPI接続までUIの権利根拠にしない。既存ケース期間の短縮や自動個人課金を追加しない。
