# ADR-0006：開発時の権限切替と非公開データを含まないぼかし

日付：2026-09-26。決定責任者：テックリード・會田 純一朗。状態：採用（公開・決済接続は未承認）。TOM-38/TOM-39。

## 背景と決定

Androidで役割/プランによる画面差を随時確認したいという最新依頼に対応する。支払者と回答担当を単一管理者にしない。開発設定は `__DEV__` に限定し、ローカルの合成状態だけを変更する。実利用権への接続・永続化・URLからの指定は行わない。

無料枠は初回確定時の2IDを固定。フィルタより前に判定し、詳細/更新も再検証する。ぼかしはFigma指定ノードの柔らかい表現を参考に、実タスクを含まない装飾で描く。見た目だけの秘匿をセキュリティと呼ばない。

支払権限者はプラン確認、招待家族等の支払権限なしの承認メンバーは契約者への依頼へ分岐する。Stripe未作成の明示回答に従い準備中の画面までとし、架空URL・送信完了・課金成功を作らない。

## 影響

C18の旧リンクなし方針は希望UXとして更新するが、ストア適合性やG条件を満たしたとは扱わない。将来のサーバー認可/Stripe接続は別チケット。常設の開発バナー除去は維持。物理実機/iOS/本番サーバー検証は別。

詳細と受入条件は[SSOT](../ssot/access-preview.md)。
