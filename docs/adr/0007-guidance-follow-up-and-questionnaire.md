# ADR-0007 — 質問分岐と法要の残作業を独立して管理する

- 日付：2026-09-26
- 決定責任者：テックリード・會田 純一朗
- 状態：採用、実装前記録。公開承認ではない
- チケット：TOM-42/43/45。TOM-44はPOモック待ち

## 背景

再監査で法要本体を完了にすると関連作業が消えて全完了になる不具合、初回8回答が抽出に未接続、実際の法要完了確認と相続案内の未接続、ケアの小さな選択の不足を確認。會田は必要なら10問を超える質問追加と、文書先行の実装を指示した。香典台帳は別途POがモック作成中との最新回答に従い保留する。

## 決定

1. [詳細SSOT](../ssot/guidance-completion-and-questionnaire.md)と別リポジトリ仕様・設計を先に更新する。
2. ADR-0004の初回10問維持を置換。IDベースの条件付き質問と最終一括確定を採用し、初回の既存回答も安全な確認候補の絞り込みに使う。
3. 法要の完了回答、個別作業進捗、準備候補の発行履歴を分離。作業が一覧から消えただけで全完了にしない。任意作業の明示対象外は完了と区別する。
4. 相続の注意は暦日と実施確認の両契機を持つが、法的期限は算出しない。ケアは気分から推定せず本人が小さな行動を選ぶ。
5. フロント検証可能な範囲を今回の成果物とし、未接続API/保存/通知・監修を完成扱いしない。

## 代替案・影響

関連作業の一括完了は誤記録になるため不採用。進捗レコードの有無から既発行を推測すると未操作タスクを失うため、専用の最小履歴を持つ。全員に全質問を聞く方式は不要な負担になるため条件付きにする。モック未受領の香典項目を推測して作ることはしない。将来のAPIでは確定回答・進捗・履歴を同じ改訂のトランザクションで保存する必要がある。
