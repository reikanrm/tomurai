# ADR-0005: 共通の日付選択カレンダー

日付：2026-09-26 / 状態：採用（公開承認ではない）
決定責任者：テックリード・會田 純一朗 / Linear：TOM-37

## 背景

死亡日・法要予定日が直接入力だけで、日付の見通しとモバイルでの選びやすさが不足している。利用者からカレンダー部品の改善依頼。

## 決定

既存の紙色・深緑・Noto Sans JPを継承するインラインの共通カレンダーをReact Nativeで実装。月送り・年月指定・直接入力の両方を提供する。新規依存・モーダル・外部サービスは増やさず、Webとネイティブの構造を共用する。詳細は[SSOT](../ssot/date-picker.md)。

TOM-40追加決定（2026-09-26、會田 純一朗）：死亡日の質問での初回自動展開をやめ、共通部品の既定値（閉じる）を使う。戻る/再編集でも閉じて開始し、入力値は保持する。日付欄からの手動開閉、制約、最終確認の責務は変更しない。

## 理由と制約

OS標準ピッカーだけではWebとネイティブの意匠が揃わず、入力だけでは日付の位置関係を確認しづらい。自前の小さな共通部品は既存のデザインと不明日・範囲制約を保持しやすい一方、アクセシビリティと暦計算を自分たちで検証する必要がある。親画面の検証も残し、初期表示日を回答とみなさない。相続期限や宗教上の必須性に関する変更はない。
