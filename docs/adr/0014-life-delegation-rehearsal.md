# ADR-0014：代理入力の検証を合成メモリ状態へ隔離する

- 日付：2026-09-27
- 状態：採用（ローカル操作確認のみ）
- 決定責任者：テックリード・會田 純一朗
- 対応：TOM-70（親TOM-62）、C06/R08/R13/R19/R43/R46

## 決定と根拠

第1〜9問の代理入力方針を仮データの一連操作と権限テストまで実装することを利用者が明示承認した。実認証/保存/家族同期/インフラは設計確認待ちのまま。

通常の認可を緩めず、専用状態機械と画面で合成ノート・2項目・固定例文だけを操作する。開発の法人プレビューまたは明示的な検証ビルドだけ入口を出す。メモリ以外へ書き出さず、終了/離脱で消す。既存の色/書体と親本人/社員の視点、確定内容/下書きの比較を使い、試験用であることを明示する。

通常のlife-accessで代理入力を開放する案は、実認証/本人承認の証拠がないため採らない。自由記述は個人情報や未監修項目を集め得るため採らず、固定例文の選択で入力/競合を検証する。後の本番実装はサーバー状態/時計による再検証が必要で、合成ロール切替は本人認証ではない。

期限/取消/資格失効と内容保持を分離し、古い委任ID/内容版/状態revisionを拒否する。満了時点で停止し、資格復活や新規承認で内容確定/共有を自動実行しない。保存条件は既存C15/R37を維持する。

## 検証

正常/否定試験、日英UI、型/全テスト/Webビルド、通常ビルドでの入口無効、docs同期を行い証跡へ記録する。実接続/監修/物理端末/公開は別ゲート。[仕様正本](../ssot/life-delegation-rehearsal.md)、[証跡](../development/evidence/TOM-70.md)。
